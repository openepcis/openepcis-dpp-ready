# CIRPASS-2 EU DPP Battery Ontology — upstream mirror

**Status:** Mirror (upstream Version 0.4.0 **DRAFT**, issued 2026-07-07, modified 2026-11-03; CC BY 4.0) • **Layer:** 2 (sectoral upstream profile of the CIRPASS-2 EU DPP pilot programme) • **Licence:** CC BY 4.0, Apache 2.0 fallback as software (upstream, since 2026-10-30)

This module mirrors the **EU DPP Battery Ontology**, the CIRPASS-2 sectoral
extension of the [EUDPP Core Ontology](../cirpass2-eudpp/README.md) for
battery passports under Regulation (EU) 2023/1542. Authoritative sources:

- **Documentation:** <https://cirpass-2.github.io/ontologies-docs/Battery/battery-ontology/index-en.html>
  (umbrella) and `…/Battery/battery-ontology-complete/index-en.html` (merged);
  development repository <https://github.com/CIRPASS-2/ontologies-battery>
- **Files:** <https://github.com/CIRPASS-2/ontologies-docs> (`Battery/`), pinned
  by commit in `scripts/sync-cirpass2.ts`
- **Namespaces:** umbrella `https://w3id.org/eudpp/battery#` (prefix `bat`) plus
  thematic modules `battery-performance`, `battery-materials`, `battery-labeling`
  and SKOS vocabularies `battery-categories`, `battery-chemistries`,
  `battery-statuses`, `battery-extinguisher-classes`, `battery-locations`,
  `battery-metals`, each at `https://w3id.org/eudpp/battery-<module>#`.

Upstream states the ontology was "developed against the CIRPASS-2 CORE ontology
v2.0.5 (refresh of 25 August 2026)"; CORE has since moved to 2.1.0 (see the
EUDPP mirror). The file also carries MIREOT copies of a few CORE terms
(`eudpp#Product`, `eudpp#MaterialOfComposition`, …); they are outside the
battery namespaces and are indexed by the CORE mirror, not here.

## What this module ships

| File | Provenance | Purpose |
|---|---|---|
| `ontology/battery.ttl` | Generated by `pnpm sync:cirpass2-battery` — verbatim copy of `Battery/battery-ontology-complete/ontology.ttl` | Source of truth for the build pipeline. Preserves upstream IRIs. |
| `json/cirpass2-battery.json` | Generated by `pnpm build:json` | Vocabulary browser data for ref.openepcis.org. |

## Relationship to the OpenEPCIS ontology

Mirroring is for **indexing and browsing only**. The OpenEPCIS battery module
(`eu/battery`, prefix `eubat:`) anchors to the CORE EUDPP terms where audited;
its alignment to this draft sectoral ontology is a follow-up SKOS audit once
upstream leaves DRAFT. Nothing is imported, subclassed or rebranded.

## Sync

```bash
pnpm run sync:cirpass2-battery   # network: fetches the pinned file, rewrites ontology/battery.ttl
pnpm run build:json
```

When upstream releases a new version: bump `UPSTREAM_COMMIT` in
`scripts/sync-cirpass2.ts`, re-run the sync in its own commit, update `VERSION`
and record the delta in `CHANGELOG.md`.
